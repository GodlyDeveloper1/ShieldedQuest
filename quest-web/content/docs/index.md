# Getting started

Shielded Quest hides shielded Zcash behind a riddle. A creator writes clues and answers; each
right answer unlocks the next clue; the final answer unlocks the key to a prize pot. Anyone can
check the prize is real, guesses never leave the solver's browser, and nobody can see who won.

> **Testnet only.** Everything here uses Zcash testnet coins (TAZ), which have no value.

## Try it in a minute

1. Open the **[one-minute hunt](/demo)**. It's a short hunt with the answers shown in the hints.
2. Answer each clue. Watch the spinner: your browser is doing the work, not our server.
3. After the last answer, claim the prize: paste a shielded testnet address, or send it back to
   the practice pool if you don't have a testnet wallet.
4. Open the hunt's **Verify it yourself** section to see how anyone can check the prize without
   trusting us.

## Make your own

Go to **[Create a hunt](/create)**. You'll write the clues and answers, save a backup, lock the
hunt, and fund the prize. The [guide for creators](/docs/creators) walks through it.
